# Interview｜軟體工程師技術面試基礎

給已有開發經驗、想補齊基礎並準備面試的人。以通用軟體工程觀念為主，用 C# 與 SQL 連接日常後端開發。

讀完的目標是：能用自己的話解釋概念，說出用途與代價，並接住一兩層追問。優先收錄常見且實用的主題；這裡的「優先」是複習建議，並非所有公司的題目頻率統計。

## 從哪裡開始

- 面試前時間有限：先讀 [快速複習](quick-review.md)，遇到說不清楚的問題再回到章節。
- 想補基礎：依下表順序閱讀。每次讀完一節，闔上筆記，用 30～60 秒說明一次。
- 準備自己的例子：挑一個做過的 API，解釋它怎麼驗證權限、查資料、處理併發、回應錯誤與追查問題。

## 每節怎麼讀

每個編號主題都包含「白話與用途」「實際場景」「面試回答」「追問／易錯點」。先理解，再練回答；回答稿是起點，可以換成自己的經驗。

面試回答可用這個順序：**一句話說是什麼 → 解決什麼問題 → 一個例子 → 一個限制或代價**。不用第一句就把所有術語塞滿。

## 範例約定

- C# 範例以現代 .NET 的一般寫法呈現；多數是獨立片段，省略常見 `using`。有外部相依或前提會在旁邊註明。
- SQL 優先使用通用語法；參數符號、隔離層級與執行計畫等依資料庫而異，差異會明示。SQL 是教學範例，本專案沒有建立或操作實際資料庫。
- 這是 Markdown 筆記專案，不需要安裝套件或啟動服務。章節中的程式碼不是一套可直接部署的應用程式。
- .NET、PostgreSQL、HTTP 與資安易混淆處已參照官方文件；相關段落附有延伸連結。查閱日期：2026-10-05。

## 收錄邊界
